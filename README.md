# Pico 74xx IC Tester

A Raspberry Pi Pico-based tester for common 74xx-series logic ICs.

The tester supports 14-pin, 16-pin, and 20-pin DIP logic ICs using a single ZIF socket, selectable DUT voltage, protected GPIO lines, package auto-detection, RGB status indication, button control, optional OLED output, and USB terminal output.

This project was designed as a practical bench tool for checking suspect 74LS, 74HC, 74HCT, and related logic ICs used in retro computer and electronics projects.
