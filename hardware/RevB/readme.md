# Board v0.2 - Rev B

## Current Hardware Revision

### Features

* 14-pin, 16-pin and 20-pin DIP IC support
* 3.3V and 5V DUT support
* MCP23017 user interface subsystem
* RGB status LED
* Active piezo buzzer
* USB serial output
* SSD1306 OLED support
* Rotary encoder user interface
* Two-board architecture (Main Board + UI Board)
* Self-powered operation
* On-board 5V and 3.3V regulation
* Reverse-polarity protection
* Polyfuse protection

### Current Status

* PCB Rev B Arrived
* Main Board assembled and testing
* UI Board assembled and testing
* Rev B hardware validation Finished
* IC database expansion Finished (User updates to IC's Encouraged)
* Device-specific test Finished
* Rev C development on going

---

## Current Limitations

* No automatic DUT current limiting
* No over-current shutdown
* Limited sequential logic support
* No automatic IC identification
* OLED user interface still under development
