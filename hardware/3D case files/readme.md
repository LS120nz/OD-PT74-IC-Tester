# OD-PT74 3D Printed Case

This directory contains the 3D printable enclosure for the **OD-PT74 Rev-C**.

## Design

- Designed using **FreeCAD**
- Tested on a **Creality K1**
- Optimised for **PLA+**

## Included Files

| File Type | Description |
|-----------|-------------|
| **FCStd** | Original FreeCAD source files |
| **3MF** | Print projects with print settings |
| **STL** | Standard files ready for slicing and printing |

## Project Preservation

The original FreeCAD source files are included so the enclosure can be modified, repaired or adapted for future revisions of the OD-PT74.

This follows the project's preservation philosophy of including original design files wherever practical.

## CAD Software

The enclosure was designed using **FreeCAD 0.21**.

The supplied `.FCStd` files can be opened with newer versions of FreeCAD, although the user interface and available tools may differ.

## Source Files

The FreeCAD (`.FCStd`) files are provided so the enclosure can be modified or adapted for future revisions.

The STL files are ready for 3D printing.

The 3MF files are provided for users who wish to use the recommended print settings.

> [!NOTE]
> The 3MF files contain the slicer settings used to print the enclosure shown throughout this documentation. Users of other printers or slicers can use the STL files together with their own preferred print settings.

### Recommended Print Settings

The supplied 3MF files have been prepared for:

- **Printer:** Creality K1
- **Nozzle:** 0.4 mm
- **Material:** PLA filament

These settings are provided as a starting point and may be adjusted to suit your own printer and preferred material.
