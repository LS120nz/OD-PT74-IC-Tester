## Contents

Native KiCad project files.

### gerbers/

Manufacturing Gerber files for PCB fabrication.

### bom/

Bill of materials.

### images/

Rendered PCB images and schematics.

---

## Rev A Features

- Raspberry Pi Pico based
- 20-pin ZIF socket
- 14/16/20-pin package support
- 3.3V / OFF / 5V DUT selection
- GPIO protection network
- MCP23017 I/O expander
- RGB status LED
- Passive piezo buzzer
- Optional OLED support
