\# OD-PT74 UI Connector



This document defines the board-to-board connector assignments between the OD-PT74 Rev-C Main Board and Top Board.



These connector assignments are provided for hardware maintenance, future revisions and third-party expansion boards.



\## Compatible Hardware



• OD-PT74 Rev-C Main Board

• OD-PT74 Rev-C Top Board
