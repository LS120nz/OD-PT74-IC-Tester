# OD-PT74 Rev-C Top Board

This directory contains all design, manufacturing and reference files for the **OD-PT74 Rev-C Top Board**.

## Contents

### BOM

Contains the Bill of Materials in both human-readable Markdown and KiCad-generated CSV formats.

### KiCad

Contains the complete KiCad source project, including the schematic, PCB layout and associated project files.

### Gerbers

Contains the Gerber and drill files generated from the final Rev-C design.

### Images

Contains reference images, including the schematic, PCB layout and 3D board render.

### OD-PT74_Top.zip

A ready-to-upload archive containing all manufacturing files required for PCB fabrication.
