# Bill of Materials

This directory contains the manufacturing and assembly files for the **OD-PT74 Rev-C**.

## Files

| File | Purpose |
|------|---------|
| `top_board_BOM.md` | Human-readable parts list |
| `top_board.csv` | KiCad Bill of Materials export |
| `top_board_all.pos` | Pick-and-Place data for PCB assembly |

The CSV files were generated from the final Rev-C KiCad project.
