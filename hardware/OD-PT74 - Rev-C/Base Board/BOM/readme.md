# Bill of Materials

This directory contains the manufacturing and assembly files for the **OD-PT74 Rev-C**.

## Files

| File | Purpose |
|------|---------|
| `OD-PT74_BOM.md` | Human-readable parts list |
| `OD-PT74.csv` | KiCad Bill of Materials export |
| `OD-PT74_all.pos` | Pick-and-Place data for PCB assembly |

The CSV files were generated from the final Rev-C KiCad project.
