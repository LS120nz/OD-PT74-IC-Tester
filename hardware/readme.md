## Board v0.1-revA

## Current Hardware Revision

Current features:

- 14/16/20-pin support
- 3.3V and 5V DUT support
- MCP23017 UI subsystem
- RGB status LED
- Active buzzer
- USB serial output
- optional OLED support

Status:

- PCB-Rev_A ordered / De-bug and fixed.
- selection of 14/16/20 pin ics tested.
- PCB-Rev_B ordered / to be built and tested

## Current limitations

- No automatic current limiting yet
- No overcurrent shutdown
- No sequential logic support yet
- No auto IC identification yet
---

## Planned features
