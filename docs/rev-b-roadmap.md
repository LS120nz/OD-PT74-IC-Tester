# Rev B Roadmap

Ideas for a future hardware revision.

## Power Safety

- Automatic DUT power switching
- Current sensing on V_OUT
- Overcurrent shutdown
- Shorted IC detection
- Firmware-controlled power enable

## UI Improvements

- Improved OLED menu
- More detailed fail reporting
- Optional encoder instead of buttons
- More LED status indicators

## Test Features

- More 74xx IC definitions
- Sequential logic testing
- Pulse generation mode
- Logic probe mode
- Continuity test mode

## Hardware Expansion

- 24-pin / 28-pin ZIF support
- Better DUT insertion detection
- USB-C power input
- Enclosure/front-panel design
