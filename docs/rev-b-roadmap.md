# Rev B Roadmap

## Overview

Rev B focuses on transforming the Rev A proof-of-concept into a self-contained bench instrument.

Goals include improved usability, standalone operation, enhanced diagnostics, and a more robust mechanical design.

## Hardware

### Self-Powered Operation

* External DC barrel jack input
* On-board 5V and 3.3V regulation
* Polyfuse protection
* Reverse-polarity protection
* Power switch
* Power indicator LED

### User Interface

* SSD1306 128x64 OLED display
* Rotary encoder navigation
* TEST button
* NEXT button
* RGB status LED
* Piezo buzzer

### Mechanical Improvements

* Two-board architecture
* Dedicated user-interface board
* Dedicated controller/power board
* 3D printed enclosure
* Improved ergonomics
* Easier access to ZIF socket and controls

## Firmware

### Enhanced Test Selection

* Device-specific test menus
* Interactive test selection
* Improved diagnostics
* Expanded IC support

### Future Enhancements

* Device information pages
* Pinout display
* Failure diagnostics
* User test profiles

## Status

Current Stage: PCB design and mechanical layout.

Target: Rev B prototype hardware validation.
