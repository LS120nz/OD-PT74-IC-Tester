OD-PT74 PCBWay Shared Project
Project Title

OD-PT74 Logic IC Tester

Short Description
-------------------
The OD-PT74 is an open-source RP2040-based 74xx TTL and CMOS logic IC tester designed for hobbyists, repair technicians and electronics enthusiasts. It supports 14, 16 and 20-pin DIP devices and features an intuitive OLED display with rotary encoder navigation. Complete firmware, hardware source, enclosure files and build documentation are available on GitHub.

Features
----------
Supports 14, 16 and 20-pin DIP logic ICs
Supports both TTL and CMOS logic families
RP2040 microcontroller
OLED display
Rotary encoder user interface
Quick, Full and Soak test modes
Open-source firmware
KiCad hardware source included
FreeCAD enclosure source included
Complete build documentation
