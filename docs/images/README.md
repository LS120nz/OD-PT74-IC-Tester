# Images

This directory contains all images used throughout the GitHub documentation for the **OD-PT74 Pico 74xx IC Tester**.

Images are organised by document or purpose to simplify maintenance and keep the documentation consistent.

## Folder Structure

- **build/** – Hardware assembly photographs.
- **firmware/** – Thonny and firmware installation screenshots.
- **hardware/** – Product photographs and hardware overview images.
- **usage/** – Operating the tester and example test results.
- **testing/** – Test examples and validation images.
- **branding/** – Logos, labels, and other branding artwork.

When adding new images:

- Use descriptive filenames.
- Keep images grouped in the appropriate folder.
- Optimise images for GitHub viewing where practical.
- Update the relevant documentation if image filenames or locations change.
