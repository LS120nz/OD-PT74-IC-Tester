## Community IC Contributions

The OD-PT74 74xx Tester was designed to allow additional IC support to be added over time.

If you develop and validate support for a new device, contributions are welcome.

### Please Include

* IC part number
* Device family (74LS, 74HC, 74HCT, etc.)
* Test function source code
* Pin mapping used
* Test methodology
* Hardware validation results
* Quick / Full / Soak test results
* Any known limitations

### Validation Requirements

Before submitting a new IC definition, please verify the device on physical hardware.

At minimum:

* Quick Test PASS
* Full Test PASS
* Soak Test PASS (recommended 50 cycles)

### Goal

The aim of the project is to build a growing library of verified logic IC tests that can be shared with the community.

Verified contributions may be incorporated into future firmware releases and credited to the contributor.

### Notes

OD-PT74 74xx Tester focuses primarily on standard 74xx-series logic devices.

More specialised devices and advanced diagnostic functions are planned for the future Logic IC Diagnostic Analyzer.

## Project Preservation

The OD-PT74 repository is intended to preserve everything required to build, modify, and maintain the project. Where practical, original source files are included alongside generated outputs to ensure the project remains usable for future builders and contributors.
