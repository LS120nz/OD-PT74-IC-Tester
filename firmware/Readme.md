\# Firmware



This directory contains the firmware for the \*\*OD-PT74 Pico 74xx Logic IC Tester\*\*.



\## Current Release



\- Hardware: Rev-C

\- Firmware: v1.0.0



\## Files



| File | Description |

|------|-------------|

| `main.py` | Main application firmware |

| `ssd1306.py` | SSD1306 OLED display driver |

| `stats.json` | Automatically created after testing ICs (do not copy manually) |



\## Installation



1\. Install the supported version of MicroPython onto the Raspberry Pi Pico.

2\. Copy `main.py` and `ssd1306.py` to the Pico.

3\. Reset the Pico.

4\. The OD-PT74 will boot automatically.



For detailed installation instructions, see the \*\*Firmware Guide\*\*.
